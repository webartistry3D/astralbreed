🔧 HOW IT WORKS
════════════════════════════════════════════════════════════════════════════

ABOUT SECTION FLOW:
───────────────────
User scrolls into About section
    ↓
IntersectionObserver triggers (threshold: 50%)
    ↓
ScrollLockManager.lock("about", 1200ms)
    ↓
FullPage.tsx: Lenis scroll prevented
    ↓
AOS animations play uninterrupted (900ms)
    ↓
Lock expires after 1200ms
    ↓
User can scroll again → Continues to Services


SERVICES SECTION FLOW:
──────────────────────
User scrolls into Services section
    ↓
IntersectionObserver triggers (threshold: 50%)
    ↓
ScrollLockManager.lock("services", Infinity)
    ↓
Wheel event listener catches all scroll inputs
    ↓
   ├─ If scrolling down AND not at last card:
   │  → Prevent default
   │  → Animate to next card (750ms)
   │  → Lock remains active
   │
   ├─ If scrolling down AND at last card:
   │  → Release lock
   │  → Allow normal scroll
   │  → User continues to Skills section
   │
   ├─ If scrolling up AND not at first card:
   │  → Prevent default
   │  → Animate to previous card (750ms)
   │  → Lock remains active
   │
   └─ If scrolling up AND at first card:
      → Release lock
      → Allow normal scroll
      → User continues to About section
